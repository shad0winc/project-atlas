# Atlas Infrastructure

This directory contains production infrastructure configuration for Project
Atlas.

## Directories

- `caddy/` — Reverse proxy and HTTPS configuration
- `cloudflare/` — DNS and Cloudflare integration documentation
- `docker/` — Docker network and runtime configuration
- `security/` — Security policies and hardening configuration

Sensitive credentials, API tokens, private keys, and generated certificates
must not be committed to this repository.
