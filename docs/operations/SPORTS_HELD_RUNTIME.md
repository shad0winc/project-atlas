# Held Sports runtime provenance

The normal schema-3 live entry point continues to refuse. A separate Python API,
`deployment-sports-provenance.check_live_held(native_module, record, context)`,
verifies source and image provenance during a continuously held Sports cutover.
It supplies no command-line execution, publisher, maintenance release or playback
acceptance. Ordinary schema-1/2 verification retains its active-authority checks.

The context is trusted host adapter code. Its `exclusion()` validates an inherited
exclusive scheduler lock; `verify_hold()` verifies enabled maintenance, persistent
scheduler and control exclusions, stopped producers, and the current publication.
It returns the exact documented `HELD_FIELDS`, including the candidate manifest,
base/current identifiers and owned marker/context pins. The marker and authority
condition have fixed production path mappings. `verify_configuration(role, row)`
compares every effective replacement Config, HostConfig, mount and network field
against the independently admitted private replacement contracts. Only exact
`True` accepts that configuration; serialized receipts are not adapters.

The verifier independently checks inactive authority properties, unchanged native
unit bytes, the exact condition drop-in, matching hold marker and absence of a
listening control socket. It shares the existing native ingress image, source,
mount and application-user checks. It verifies effective Sports images, installed
backend files and existing writer/controller provenance without importing Django
applications. Running, healthy container identity and configuration must remain
stable; mount ordering is normalized. Hold and manifest checks bracket the work.

The returned scope is `held-sports-provenance-only`. It grants neither runtime
acceptance nor production execution. Registry/ledger checks, worker environment,
private playback, truthful current-pointer publication and final producer/hold
release belong to the integrated guarded driver, which is still pending. API
maintenance-toggle refusal while authority is held also remains an integration
acceptance check. No producer service is stopped by this source change.
