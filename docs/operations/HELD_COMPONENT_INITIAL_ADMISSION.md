# Initial held component admission

This read-only coordinator derives a six-surface native plan from verified staged
source, a manifest-bound authority probe, exact execution recipes, retained target
and rollback inspection profiles, and current healthy container observations.
The original recovery owner and a genuinely held inherited scheduler flock are
required. The native journal plan validator checks protected evidence and artifact
pins. Initial owner/current/maintenance identities and the entire Docker inventory
must remain stable throughout admission.

The target inspection delta is reproduced independently: API/Portal immutable
images and source/build labels, one read-only API authority socket mount and its
environment key, and two read-only Caddy binds redirected to the generation. All
other profile fields must remain equal to rollback. The currently running
components must match the rollback profiles exactly after the existing bounded
inspection normalization.

Source remains staged; the authority is absent; installed, staged or retained
unit collisions refuse. The result is a private draft plan, with unit preparation
explicitly outstanding. It is not a production journal, execution authorization,
publication candidate, owner release or public acceptance. No mutation method is
available through the admission adapter. New source still needs full validation
and protected source promotion before a production coordinator may execute it.
The existing ordinary-update, schema-2 inheritance and restore refusals remain.
